# Animal Shelter Kata

This Kata consists in implementing an animal shelter where animals can be dropped off and adopted.

---

## 🎯 Step 1: Drop Off and Adopt

Create an animal shelter with the following features:
- You can **drop off** an animal to the shelter.
- You can **adopt** an animal from the shelter.

### Rule:

You can only adopt the animal with the **oldest arrival** to the shelter.

---

## 🚀 Step 2: Adopt by Species

In addition to the method to adopt the oldest animal, we'd like to add two features:

- You can adopt the **dog** with the oldest arrival to the shelter.
- You can adopt the **cat** with the oldest arrival to the shelter.
